Clients are no longer equal.

- The constructor takes an optional third argument `tiers`, a map from tier name
  to `[limit, window]`. A limit of `null` (`None`) means unlimited.
- `allow` and `retry_after` take an optional third argument `tier`. Without it,
  the constructor's `limit` and `window` apply. An unknown tier raises
  `ValueError`.
- An unlimited request is always allowed, and `retry_after` is `0.0`.
- A client's tier can change between requests. History belongs to the client:
  requests made under one tier count when the next request is judged under
  another tier's limit and window.
- Add `count(client_id) -> int`: how many of the client's requests have been
  allowed, across all tiers. Unlimited requests still count — the number feeds a
  dashboard.

Memory should stay bounded for a client that keeps calling: forget timestamps
that no tier can still see.
