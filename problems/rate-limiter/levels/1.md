An internal API gateway fronts a handful of backend services. It has no rate
limiting, and one misbehaving client can starve everyone else. Build the rate
limiter the gateway calls on every request.

Implement the `RateLimiter` class:

- `RateLimiter(limit, window)` — at most `limit` requests per `window` seconds.
- `allow(client_id, now) -> bool` — whether the request at time `now` is
  allowed. An allowed request is recorded; a rejected one is not.

The limiter never reads a clock: `now` is passed in, in seconds, and never
decreases between calls.

**The rule — sliding window.** A request at `now` is allowed if fewer than
`limit` *allowed* requests fall in the half-open interval `(now - window, now]`.

In this level every request comes from the same client.
