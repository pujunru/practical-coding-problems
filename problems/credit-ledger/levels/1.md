A GPU cloud sells compute credits. Build the ledger that tracks one
customer's credit balance.

Implement the `CreditLedger` class:

- `CreditLedger()` — a ledger with balance 0.
- `add(timestamp, amount) -> None` — grant `amount` credits.
- `charge(timestamp, amount) -> bool` — spend `amount` credits. If the balance
  is smaller than `amount`, nothing is spent and it returns `False`. There is no
  partial charge.
- `balance(timestamp) -> int` — the balance at `timestamp`.

At this level calls arrive in timestamp order.
