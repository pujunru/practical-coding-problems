Build the core of a bank's ledger. Every method takes a `timestamp` first;
timestamps are integers and strictly increase from one call to the next.

Implement the `Bank` class:

- `Bank()` — an empty bank.
- `create_account(timestamp, account_id) -> bool` — open an account with
  balance 0. Returns `False` if the account already exists.
- `deposit(timestamp, account_id, amount) -> int | None` — add `amount` and
  return the new balance, or `None` if the account does not exist.
- `transfer(timestamp, source_id, target_id, amount) -> int | None` — move money
  and return the **source's** new balance. Returns `None` (and changes nothing)
  if either account is missing, the two ids are the same, or the source has less
  than `amount`.
