Fields can now expire. These methods take a `timestamp`; within a test case
timestamps strictly increase, and cases at this level use only these methods.

- `set_at(key, field, value, timestamp) -> None` — like `set`; the field never
  expires.
- `set_at_with_ttl(key, field, value, timestamp, ttl) -> None` — like `set`, but
  the field exists only during `[timestamp, timestamp + ttl)`.
- `get_at(key, field, timestamp) -> str | None`
- `delete_at(key, field, timestamp) -> bool` — `False` if the field is missing
  or has already expired.
- `scan_at(key, timestamp) -> list[str]`
- `scan_by_prefix_at(key, prefix, timestamp) -> list[str]`

Setting a field again replaces both its value and its expiry.
