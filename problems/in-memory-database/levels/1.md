Build a small in-memory database. A **record** is identified by a `key` and
holds any number of **fields**, each with a string value.

Implement the `InMemoryDB` class:

- `InMemoryDB()` — an empty database.
- `set(key, field, value) -> None` — set the field, creating the record if
  needed and replacing any previous value.
- `get(key, field) -> str | None` — the field's value, or `None`.
- `delete(key, field) -> bool` — remove the field. Returns `True` if it existed.
