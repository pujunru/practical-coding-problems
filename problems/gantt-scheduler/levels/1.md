A project is a set of tasks. Each task takes a whole number of days and may
have to wait for other tasks to finish first. Build the scheduler that turns
that into a Gantt chart: when every task starts and ends.

Implement the `Gantt` class:

- `Gantt()` — an empty project.
- `add_task(name, duration, depends_on) -> None` — add a task that takes
  `duration` days and cannot start until every task named in `depends_on` has
  finished. Raises `ValueError`, and adds nothing, if `name` already exists, if
  any name in `depends_on` is not a task yet, or if `duration < 1`.
- `start(name) -> int` — the earliest day the task can start: `0` if it has no
  dependencies, otherwise the latest finish among its dependencies.
- `finish(name) -> int` — `start(name) + duration`.
- `length() -> int` — the day the whole project is done: the latest finish of
  any task, or `0` for an empty project.

`start` and `finish` raise `KeyError` for a name that is not a task.

Any number of tasks can run at the same time.
