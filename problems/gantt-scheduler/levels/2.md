The plan changes after it is written, and the project manager wants to know
which tasks they cannot afford to let slip.

- `set_duration(name, duration) -> None` — change a task's duration. Everything
  that waits on it moves accordingly. Raises `ValueError` if `duration < 1`.
- `add_dependency(name, dep) -> bool` — `name` must now also wait for `dep`.
  If that would make a task wait, directly or indirectly, on itself, nothing
  changes and it returns `False`. Otherwise it returns `True` (also when the
  dependency already existed).
- `slack(name) -> int` — how many days the task can start late without making
  the project longer. Push every task as late as it can go while the project
  still ends on `length()`; slack is that latest start minus `start(name)`.
- `critical() -> list[str]` — the tasks with zero slack, ordered by start day,
  then by name.

Unknown task names raise `KeyError`.
