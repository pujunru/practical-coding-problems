Build a key-value store that keeps every version of a value, so callers can
ask what a key held at any point in time.

Implement the `TimeMap` class:

- `TimeMap()` — an empty store.
- `set(key, value, timestamp) -> None` — record `value` for `key` at
  `timestamp`.
- `get(key, timestamp) -> str | None` — the value of the latest version at or
  before `timestamp`, or `None` if there is none.

At this level, timestamps for the same key arrive in increasing order. Aim for
`get` faster than a scan of every version.
