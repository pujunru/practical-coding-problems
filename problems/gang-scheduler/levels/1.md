A GPU cluster runs distributed training jobs. A job needs all of its GPUs at
the same moment — its workers talk to each other every step, so a job with half
its GPUs just sits there holding them. Build the scheduler that only ever
starts a job as a whole gang.

Implement the `GangScheduler` class:

- `GangScheduler(gpus)` — a cluster with `gpus` GPUs, all free.
- `submit(job, size) -> bool` — queue a job that needs `size` GPUs, run a
  scheduling pass, and return whether this job is now running. Raises
  `ValueError`, and queues nothing, if `job` was ever submitted before, or if
  `size < 1` or `size > gpus`.
- `finish(job) -> list[str]` — a running job completes and frees its GPUs.
  Run a scheduling pass and return the jobs it started, in the order they
  started. Raises `ValueError` if the job is not running.
- `status(job) -> str` — `"queued"`, `"running"` or `"done"`.
- `free() -> int` — the number of free GPUs.
- `running() -> list[str]` — the running jobs, sorted by name.

A **scheduling pass** goes through the queued jobs in submission order and
starts every job whose whole gang fits in the free GPUs. A job that does not
fit is passed over; a smaller job behind it may still start. A job never
starts with part of its GPUs.

Unknown job names raise `KeyError`.
