Customers can cancel, and the cancel button is retried too.

- `cancel(order_id) -> bool` — cancel the order and put its stock back. Returns
  `True` if the order is cancelled when the call returns, `False` if there is no
  such order.
- `status(order_id) -> str` — `"placed"` or `"cancelled"`. An unknown id raises
  `KeyError`.

**Cancel must be idempotent.** Cancelling an order that is already cancelled
returns `True` and changes nothing: stock is returned exactly once.

Cancelling does not free the idempotency key. A retry of the original
`place_order` still returns the same order id, and it does not place a new
order.

### Review checklist

- Read the current status first; only a `"placed"` order changes.
- Stock is put back on the transition, not on every call.
- A repeated cancel reports the same outcome as the first one.
- A cancelled order's key still replays the original result.
