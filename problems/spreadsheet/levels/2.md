Text starting with `=` is a **formula**, and `get` returns its computed value.

A formula combines numbers and cell references with `+`, `-`, `*`, `/`,
parentheses and unary minus, with the usual precedence. Spaces are ignored.
`/` is true division (`=1/2` is `0.5`).

When a formula cannot be computed, its value is an error string:

| Error | When |
| --- | --- |
| `#VALUE!` | a referenced cell holds text that is not a number |
| `#DIV/0!` | division by zero |
| `#ERROR!` | the formula is malformed |

An error in a referenced cell makes the formula show that same error.
