Build the engine of a small spreadsheet. Cells are named by column letters and
a row number: `A1`, `B7`, `AA12`.

Implement the `Spreadsheet` class:

- `Spreadsheet()` — an empty sheet.
- `set(cell, raw) -> None` — store the text `raw` in `cell`. An empty string
  clears the cell.
- `get(cell) -> int | float | str` — the cell's value:
  - text that parses as an integer comes back as an `int`, as a decimal as a
    `float`;
  - any other text comes back unchanged;
  - an empty cell is `0`.
