Add functions over **ranges**. A range `A1:B3` is the rectangle between two
corner cells, given in either order.

- `SUM(range)`, `MAX(range)`, `MIN(range)`.

Empty cells in a range count as `0`; text that is not a number makes the
function `#VALUE!`. Functions can appear anywhere a number can:
`=SUM(A1:A3)*2+MAX(B1:B2)`. An unknown function, or a function given anything
but a range, is `#ERROR!`.
